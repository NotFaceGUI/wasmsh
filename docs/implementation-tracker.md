# AI Shell 实施跟踪

用户授权：按顺序委派独立任务实现，任务模型统一为 `gpt-5.6-luna`，推理强度 `max`；主任务最后审阅。需求基线见 [项目目标](project-goals.md)、[需求设计](design/ai-shell-requirements.md)、[构建计划](guides/standalone-wasm-build-plan.md)。

执行方式：一次只运行一个实现任务，各任务使用独立 worktree。每阶段提交代码并报告验证证据；主任务检查、整合后再创建下一阶段，后续阶段继承已整合代码。最终由主任务审阅累计差异、执行针对性验证并修复发现的问题。

| 1 | 独立 WASM 构建与 CI 解耦 | 待开始 | GitHub-hosted runner、固定工具版本、无 Pyodide、实际产物测试与打包 |
